# Welcome to My Country

Mia's guide to Buenos Aires and Argentina for international friends: where to eat, barrios to explore, nights out, and trips around the country.

A static site with no build step. Open `index.html` or upload the folder to any static host.

- `index.html`: the whole guide (content, styles and tab logic)
- `photos.js`: maps each item to its photo and credit
- `images/`: every photo, max 1600 px wide, WebP
- `credits.md` / `credits.html`: source, author and license of every photo

## Swap a photo

Replace `images/<name>.webp` with a new file of the same name, then update that item's author and license in `photos.js` and `credits.md`.
